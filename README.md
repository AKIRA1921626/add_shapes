# 新たにAviutl2に追加する図形

1つ目の方法  
Figureというフォルダをダウンロードし、  
C:\ProgramData\aviutl2  
にコピーしてください。  

2つ目の方法  
Figureというフォルダの中の欲しい図形をダウンロードし、  
C:\ProgramData\aviutl2\Figure  
にコピーしてください。  

このどちらかを行えば、ここで配布している図形をAviutl2に追加することが可能です。  

**二次配布可、改変可、クレジット不要**  

以下作成時のメモ
---

Inkscapeで図形を作成し、作成したものはFigureにいれる。  

C:\ProgramData\aviutl2\Figure  
にベクター画像を配置すれば、図形として認識される。  

黒が図形の内部、白が透明な部分として認識される。  
.svgに付けている名前が図形の名前となる。  

サイズは512x512とする。  
512x512はInkscapeの"テンプレートから作成>その他"に入っているため、作成しやすいサイズであるためである。  
図形のサイズに規定はない（？）ようだが、今回はこのサイズにしておく。  

空白部分はInkscapeの初期設定だと白になり、図形の透明の部分だと認識されるため、.svgの上下いっぱいまで使用して画像を作成するといい。  

オブジェクト>オブジェクトをパスに  
で四角形などのシェイプツールで作成したオブジェクトをパスに変換できる。  

パス>統合  
で複数のパスを1つのパスに統合できる。   

パス>排他  
で重なっている複数のパスの重なっている部分だけを透明にできる。  
これで円を1つ作成しその中にもう1つ円を描き、排他を行えば、ドーナッツが完成する。  

オブジェクト>配置と整列  
で”中心を垂直軸に合わせます"と"水平軸の中心に揃えます"でオブジェクトを真ん中に配置できる。
